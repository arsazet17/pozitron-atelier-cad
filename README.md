# ПОЗИТРОН АТЕЛЬЕ CAD

Приложение для шторного ателье: замеры окон, размерные чертежи, визуализация, расчёт ткани и раскроя, сметы, договоры и согласование с клиентом.

Работает как установленное приложение (PWA) на **Android, iPhone, iPad и компьютере**. Данные хранятся на устройстве, интернет для работы не нужен.

## Установка

Откройте адрес приложения:

- **Android (Chrome)** — кнопка «Установить» на главном экране приложения или меню ⋮ → «Установить приложение».
- **iPhone / iPad (Safari)** — «Поделиться» → «На экран „Домой“».
- **Компьютер (Chrome, Edge)** — значок установки в адресной строке.

## Что готово — версия 1.0.8

- **Заказы**: список с поиском, автонумерация, карточка заказа, заказчик, помещения и окна.
- **Фото**: съёмка камерой телефона или из галереи, разметка 4 углов проёма с лупой; размеры из замеров ложатся на фото в перспективе.
- **Замеры**: проём, стена и простенки, подоконник, батарея, карниз, изделие, доп. размеры; схема с размерными цепочками, вычисление недостающих звеньев и проверка сходимости (допуск 3 мм).
- **Изделия**: портьеры, тюль, римская и рулонная шторы; полотна, сборка, ткань, подкладка, лента, пошив; карниз и монтаж.
- **Визуализация**: шторы и карниз на фото окна, цвет, прозрачность, открыто/закрыто, сохранение картинки для клиента.
- **Чертёж**: лист A4/A3 со штампом, вид спереди с размерами изделий и вид сбоку, автоподбор масштаба, экспорт SVG.
- **Раскрой**: ткань в рост и в высоту, сшивание полос, раппорт, упаковка неполных полос, карта раскроя, пояснения для швеи.
- **Смета по готовым изделиям** (для клиента): изделия по комнатам с описанием (высота, складка, сборка, карниз, полотна) и ценой готового изделия.
- **Подробная смета**: метраж ткани, шторной ленты, нитки, работы по ценам справочника, ручная правка цен, доп. строки, скидка/наценка.
- **Печать и PDF**: клиенту (смета + визуализация + размеры), смета по готовым изделиям, подробная смета, комплект для производства.
- **Настройки**: реквизиты ателье, нумерация, припуски, справочник материалов и работ, резервная копия (с фото).

## Разработка

```
npm install
npm run dev      # локальный запуск
npm test         # проверки расчётов
npm run build    # сборка в docs/ (её раздаёт GitHub Pages)
```

Все размеры — целые миллиметры. Модель размеров и цепочек: `src/model/measurements.ts`, схема: `src/drawing/`.

Публикация: GitHub Pages → ветка `main`, папка `/docs`. Версия меняется только последней цифрой: 1.0.1, 1.0.2, 1.0.3…
